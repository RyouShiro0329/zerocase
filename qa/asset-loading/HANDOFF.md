### 1.1 下載與準備

- P0：字型與選單素材；P1：入口必要圖像、常用聲音、探索配樂可播放狀態；P2：近期武器與特效；P3：低頻事件與持續聲的壓縮檔預先下載。
- 入口開始下載公開素材；真實手勢當下建立／恢復音訊、嘗試配樂，再等待必要任務。聲音關閉時不等待音效解碼。
- 登錄狀態區分 queued、fetching、decoding、ready、failed、retrying、degraded；另記錄是否下載、錯誤、嘗試次數及最後使用時間。
- 同一檔案的進行中下載共用 Promise；失敗清除進行中工作，保留冷卻紀錄。短音效缺檔時提高未來優先權，當下只用原核准備援或安靜降級，不等下載後補播。
- 圖像先準備再設定 src；缺圖保留中性框，只有同一局／節點／戰鬥且 DOM 仍有效時更新。
- 依當前節點與裝備預先準備音效，不呼叫事件產生器、不抽遭遇、不消耗遊戲 RNG。

### 1.2 工程參數

| 參數 | 候選設定 | 依據與限制 |
|---|---|---|
| 同時下載 | 一般 3；低記憶體／2G 2 | 必要任務優先；背景佇列隱藏時暫停發出新請求 |
| 同時解碼 | 1 | 避免大量解碼競爭；尚待瀏覽器掉幀量測 |
| 每輪嘗試 | 最多 3 次 | 0.5／1.5 秒退避；不使用遊戲亂數 |
| 請求／準備逾時 | 12 秒 | 備用格式共用該次請求的取消訊號 |
| 失敗冷卻 | 30 秒 | 手動重試可重設；online 不視為必定連線成功 |
| 入口前景等待 | 25 秒 | 逾時顯示重試；僅有合理備援時可繼續 |
| 單人演出前準備 | 最多 1200ms | 原演出時間軸啟動前；不改 QTE 反應時間；多人不等各端 |
| 音效解碼預算 | 一般 96 MiB；低記憶體 32 MiB | 原音效主要格式約 75.7 MiB（原始取樣率）；瀏覽器可能重採樣至 48kHz。一般預算依盤點提高，保留既有完整 loadSounds 介面；低頻資源平常只先下載壓縮檔。尚待瀏覽器峰值驗證 |
| 圖像解碼預算 | 48 MiB | P1 圖像約 35.36 MiB；其他特效按裝備／使用需要準備，非全部入口解碼 |

記憶體以實際 AudioBuffer 長度及圖像尺寸估算，依最近使用釋放未固定保留的資料。正在播放或演出的資源保留；預算是保留量目標，瞬間解碼峰值仍需實測。

### 1.3 快取與更新

- 頁面與 SW 各自帶當版完整內容雜湊，不讓舊 worker 重新啟動時改採新版索引。
- 快取名稱包含本遊戲 scope，鍵含相對部署根目錄及完整 SHA-256。首次尚未受 SW 控制時，載入管理器也能直接讀寫 Cache Storage。
- 完整成功回應且內容雜湊符合才寫入；404、500、不完整與不符內容不保存。
- SW 的長配樂與 Range 採明確繞過；HTTP 200／206 由原媒體伺服器處理。沒有宣稱完整離線配樂或離線多人。
- HTML 不由 SW 快取，更新索引採原網路流程。新 worker 不強制接管進行中的分頁；更新提示不會強制重整。
- 自動清理限無本遊戲分頁時執行；有舊分頁時保留。設定的「重新下載遊戲素材」僅於主選單提供，不動 localStorage、IndexedDB 存檔或設定。
- SW 不支援、註冊失敗、配額不足時回一般網路與記憶體重用。快取不是永久保存保證。
