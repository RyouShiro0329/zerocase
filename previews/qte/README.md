# QTE 逐個提示預覽 v1

基準：main 4513baa，正式版 v0.46.1。只提供離線預覽，index.html、存檔、傷害、正式版本號與待審的 v0.47.0 敵人設計均未更動。

- 現行對照：完整沿用目前 qteLocal 兩格預先顯示、120ms 換組與整組共用倒數。
- 稍快：保留 qtePer 的能力／傷勢／天賦計算後乘0.85；一次只建立一個提示，成功輸入後立即換下一個，沒有換組停頓。
- 更快：同上，倍率0.70。
- 新版總時限＝調整後每次反應預算×4；不增加逐題重置或獨立倒數，不改錯誤、鍵盤重複輸入、觸控、成功與失敗的判定。
- 前置500～1000ms等待與原序列產生方式保留。每次預設產生新路線，可勾固定對照作A/B比較。
- 普通與困難設定一致。此預覽固定四題，符合兩難度原3～4題範圍。
- 一般身手敏捷2／感知2；靈活敏捷5／5；負傷為2／2加暈眩、骨折。原天賦修正仍在公式內，但不在預覽另增選項。
- 一般身手：現行總2600ms（620×4＋120）；稍快2108ms（527×4）；更快1736ms（434×4）。新檔位比較含移除換組停頓，不宣稱只縮短15%或30%的整組時間。
- 離線HTML內嵌正楷／拉丁字型、主人既有巨噬者立繪。字型來源及OFL全文內嵌於HTML；預覽無聲，只比較反應節奏，正式音效未修改。

建立：`python3 previews/qte/build.py`。驗收：`node previews/qte/browser.cjs`（需要Playwright Chromium）。

先讓主人在Android實機比較，不合併或部署。選定後才把核准時間與逐個顯示接入正式遊戲。
