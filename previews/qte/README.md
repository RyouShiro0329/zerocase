# QTE 統一節奏預覽 v2

基準：最新 main 4513baa，正式版 v0.46.1／Build 112。index.html 與待審的敵人攻擊候選版未修改；未合併或部署。

主人試玩後選定「稍快」，要求統一、不受身手或傷勢影響。本版移除身手與速度選單，固定沿用 v1 一般身手「稍快」的 527ms 每題預算；四題共 2108ms。普通、困難相同，敏捷、感知、天賦、骨折、暈眩均不調整 QTE 時間。

成功輸入後才建立下一個提示；整組倒數持續、不重置，不提供擲骰替代。前置等待、提示位置、按錯、逾時及鍵盤長按判定沿用 v1。預設隨機路線，可固定路線重試。預覽無聲，必要字型、美術及字型授權內嵌，可在 Android 離線開啟。

建立：`python3 previews/qte/build.py`；驗收：`node previews/qte/browser.cjs`（需要 Playwright Chromium）。產物：`qa-output/qte-preview/zerocase_qte_preview_v2.html`。

設計決定變更（目前僅預覽）：取消 QTE 的能力、傷勢與天賦時間修正；所有角色用同一個稍快節奏。未變動正式遊戲的能力用途、傷勢效果或其他戰鬥規則。手機實機：待主人實機驗收。
