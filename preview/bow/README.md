# 弓弩射擊預覽（未部署）

## 本輪：命中筆觸對齊斬擊

主人已認可音效，只要求修正視覺質感。第6～12格移除厚重團塊與懸垂布片，改為細銳斜向刺痕、破碎紅黑裂線、少量非發光邊緣高光及疏密分明碎散，參照正式斬擊圖集。音效素材、音量、疊加方式、播放時序，以及動畫方向、大小、130ms飛行／160ms收尾均不變。本輪已確認runtime.js、browser.cjs、video.py與所有音檔逐位元等同前版ac63db9。

## 最新決定：弓疊加發射聲、黑紅刺入命中

主人要求弓放弦時也疊加乾爽弩發射聲，補足射出力道；疊加點1.01秒，弩維持直接播放。兩者最後皆保留肉體命中聲，圖集第6～12格改成暗紅刺入痕、黑紅碎屑與纖維撕裂，移除白色星狀發光。尺寸、方向及130ms飛行／160ms收尾不變。

## 前版決定：弩獨立發射聲

主人改為弩不播放拉弦：使用其提供Erdie bow02.wav的乾爽改作，保留彈射前緣、減弱嗡鳴與拖尾。弩100ms出箭、230ms命中；弓維持俐落版1010ms出箭、1140ms命中。兩者飛行130ms、碎散160ms不變，弩無拉弦等待。來源及授權詳見 docs/audio/LICENSES_AND_ORIGINS.md；單檔預覽的Credits亦已署名。

## 俐落版調整

主人反映太慢、不夠俐落：飛行400ms縮為130ms，命中後收尾380ms縮為160ms；完整可見動畫由780ms縮為290ms。放弦時出箭（1.01秒）不變，命中提前至1.14秒；中箭音源由1.18秒提前至0.91秒，對齊原音0.23秒主峰。原音檔、播放速度、音量、圖集、方向與大小不變。影片改以每次實際播放的時鐘紀錄，對時合成原音檔，避免雲端錄音省略靜音間隔。
