# 弓弩射擊預覽（未部署）

基準 main d4d2367，v0.45.2／Build 110。主人選擇方案一：箭矢由卡片下方射入血條，黑紅白筆觸與既有斬擊一致，命中後原地碎散。

本資料夾獨立產生單檔手機預覽，不修改正式 index.html。固定血量與重播控制只在預覽存在，並非正式戰鬥實作。

- 共用十二格箭矢圖集，362×362、4×3、透明背景。
- 弓沿用 bowdraw 與 bowimpact 原檔、原音量、1.18秒音源排程；箭矢1.01秒出現、第六格1.41秒命中，對齊 bowimpact 約0.23秒的主峰。
- 主人補充指示：弓與弩統一使用目前弓的 bowdraw＋bowimpact 原音效，同一時間軸與音量，不再保留弩的 whoosh。
- 立繪不畫特效；在資訊欄裁切，箭頭停在血條。
- 減少動態時只呈現命中格。
- build.py 內嵌必要圖像、字型、原音檔，重播按鈕可在Android離線開啟。
- browser.cjs 以兩種手機尺寸驗收、截圖並錄製有聲遊戲介面；video.py以毫秒時間基準合成，避免圖像時間量化導致音畫累積偏移。

原設計規則變更：沒有。手機實機待主人實機驗收。正式戰鬥、連線、傷害、耐久、彈藥與上弦規則尚未整合，需核准後另行實作驗收。
