# 弓弩動畫與核准音效整合 v0.46.0

主人已明確指示「好就這樣了，開始部署」。基準 main d4d2367，上一版v0.45.2／Build110；本版v0.46.0／Build111。預覽核准點9390365（PR32），正式整合另開分支，不合併預覽用固定血量與控制按鈕。

## 核准演出

- PVC弓、複合弓、手弩、十字弓，包含原本可用的武器技能、瞄準要害、雙射與反擊。
- 箭矢自敵人卡資訊欄下緣向上，射入血條；立繪區完全裁切排除。尺寸與核准預覽完全相同。
- 圖集fx/arrow-12.webp，1448×1086，4×3，362×362。第6～12格是細銳暗紅刺痕、紅黑碎線與有留白碎散，不是星光或厚重團塊。
- 每格毫秒：[25,25,25,25,30,25,20,20,20,20,25,30]，可見總長290ms。
- 弓1.01秒出箭、1.14秒命中；弩100ms出箭、230ms命中；命中後碎散160ms。
- 弓保留bowdraw，1.01秒疊加crossbowshot；弩直接發射，不播放拉弦。bowimpact音源延遲分別910ms、0ms，對齊原檔約230ms主峰。
- 主人最後確認的音量：發射聲sfxLevel('crossbowshot',1.5)，即增益1.173；肉聲sfxLevel('bowimpact',.55)，增益.4048；主混音.86。音檔、速度、音調與已核准預覽一致。
- 音檔尾音完整播放；弓命中共等1900ms、弩1000ms，射偏不播肉聲、不播命中碎痕。
- 弩貫穿的後方目標只播命中段，不再拉弦或重複發射，原本一次耗彈及傷害不變。

## 正式流程與同步

- 沿用傷害計算及扣彈位置；弩射後仍需上弦；沒有彈藥時沿用原本近戰敲擊。
- 和既有斬擊／穿刺一樣，先取得原傷害結果，等核准命中時間再刷新血條，之後才處理原有擊殺／狀態流程。沒有改傷害、抗性、耐久、技能次數或核心戰鬥規則。
- 原s事件附加可選的第4欄演出資料（arrow、id、mode、hit、follow、state）；新版隊友端播同一套音畫與狀態，不重複播放舊bowhit。保留舊bowhit／bowmiss直接呼叫API及其相容行為，不修改舊測試。
- 同步沿用既有序號水位，過期事件不覆蓋新狀態；快轉佇列直接套狀態，避免連續爆音。
- 新發射音效獨立按需載入，基礎音效載入清單維持原61種；關閉音效、取消戰鬥、切換分頁均沿用清除機制。素材失敗有合成備援，仍結算原傷害與耗彈。
- 減少動態時只呈現命中格，不播放箭矢移動。
