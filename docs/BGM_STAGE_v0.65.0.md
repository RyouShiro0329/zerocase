## 3. 畫面怎麼對上音樂
- 房主（單人就是自己）開演出時記下開始時間；畫面的進度優先用「這一段戰鬥曲實際的播放位置」（`HTMLMediaElement.currentTime`），和時鐘差 400 ms 以內才採用，否則照時鐘。
- 音樂關閉、音檔載入失敗、瀏覽器不讓播：照同一條時間軸演完、正常解鎖（不等 play／canplay／ended）。
- 晚收到狀態的隊友：從目前進度接上（不從頭），如果音樂比進度慢 300 ms 以上，只校正一次播放位置。

## 4. 鎖定與多人
- 鎖的是推進：演出期間演出層蓋住整個畫面；點按、長按、鍵盤、背包、裝備、道具、投票、戰鬥行動都作廢（本機不送出、房主收到也丟掉，不排隊）。只留「音樂：開／關」「音效：開／關」兩顆鈕。演出中按下、演完才放開的那一下不算；按住不放的鍵盤重複也不算。QTE 不受影響（演出期間不會有 QTE）。
- 權威：房主的時間到了才解除；隊友端不能自己解鎖（演完 8 秒還沒收到解除，視為異常放行，避免永遠卡住）。
- 時間：快照帶「剩餘時間」＋房主送出的時刻，隊友用來推算路上花了多久（只拿來對畫面，不拿來解鎖；差超過 5 秒就不算）。
- 單人切到背景：演出時間停住，回來把剩下的演完。多人不暫停。
- 房主斷線：接任的人接手同一個演出識別，從剩下的時間演完；舊房主的計時在隊友端不會解鎖。亂入的新先攻在演出前就排好（接手的人照樣有），演完才公布。開場演出中換房主、還沒擲先攻的，接手的人補擲。
- 自己一個人先撤離（多人）：只在自己畫面演一次結束，不鎖、不影響還在打的隊友，配樂照原本只有自己淡回 Evil。
- 存檔：演出期間不會自動存檔（自動存檔只在戰鬥結束、停在下一張卡時）；萬一舊存檔有演出欄位，讀檔時拿掉，不會重播。
