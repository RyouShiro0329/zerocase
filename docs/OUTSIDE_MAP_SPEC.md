## 1. 設計原則
1. **時間壓力是核心**：天數推進會改變整個城市；同一個地方，在不同階段去會不一樣。
2. **三層地圖**：
   - 第一層「街道段」：旅館出來到十字路口，單向，每局只走得到一條路。
   - 第二層「城市中樞」：Z0，選下一個要去的區域。
   - 第三層「區域」：每個地點，裡面分成好幾層，單向往下走。
3. **區域要深**：像後室的樓層，一個區域 3～5 層，每層 6～10 張卡，走完一個區域要 1～3 天，裡面有休息點。
4. **沿用旅館範本**：卡的種類（固定／隨機／抉擇／搜索／分岔）、`cond`、`lock`、`sign`，以及「走過的消失、不顯示已搜過」全部照舊。
5. **選項小字規則照 2026-11-20 補充**：只寫需要什麼、會用掉什麼、要付多少錢；線索用 `sign`。
6. 不做跨局記憶。「下次試不同路線」靠的是每局分岔只能選一條，不是記住上一局。

## 5. 第三層：區域（城市裡的每個地點）

### 5.1 格式
在 `ROUTE` 的格式上加「層」和「階段」：

```
AREA = { 區域id: {
  n:'聖瑪莉醫院', az:'O',                  // 警戒區域：整個區域共用（同旅館）
  ent:'O0',                                 // 從 Z0 進來的入口卡
  layers:[                                  // 第一層、第二層……往下走
    {L:'O', ws:[1,2], seq:[...], search:{...}, d:0},
    {L:'O', ws:[3,4,5], seq:[...]},         // 同一層，不同階段走不同的卡
    ...],
  out:'Z0'                                  // 走完或撤出回到哪裡
}}
```

- 同一層可以依階段寫好幾條 `seq`，進場時依照 `wStage()` 挑一條。
- 每層的最後一張是分岔：往下一層、這一層的另一條路，或撤出（見 5.3）。
- 卡、選項都可以寫 `ws:[...]`，跟 `cond` 一樣，不符合的就跳過或藏起來。
- 區域裡可以有休息點、商人、補給（跟旅館不同）。
- 現有地點的節點文字全部保留，拿來當「第一階段的第一層」，深層與其他階段的內容之後分批補。

### 5.2 一次進場的狀態
- 新增 `G.trip`：`{a:區域id, ws:進場時的階段, seen:[走過的層或地點], rs:{搜索點狀態}}`。從 Z0 進場時建立，回到 Z0 時清除。
- 區域裡的 `rtView()` 和 `rtSkip()` 看 `G.trip.seen`，不看全局的 `G.route`。這樣同一個區域下次再來，可以重新走。
- 旅館的 `G.route`、`G.rs` 不動。

### 5.3 撤出、重訪、分頭
- 撤出、重訪：照第 9 節第 1、2 題。
- 分頭搜索只在同一個搜索點裡分開，選完就會合；隊伍不會分散在不同層。

## 14. 解謎與回頭處理（主人 2026-11-20 同意四點）
像惡靈古堡：第一次走到時發現少了某樣東西，備忘錄記下來；拿到之後再回去打開。

### 14.1 兩種鎖
- **可以回頭的鎖**（`back:1`）：上鎖的門、要燒斷的封條、沒電的電梯。
  - 拿到道具後，Z0 出現「回〇〇處理〇〇」（例如「回醫院處理機房的門」）。
  - 回去**不用重走整個區域**：路上照樣花時間、抽一張街頭隨機牌；到了之後，鎖前面還有 1 張卡（依當時的階段挑，可能有敵人），然後就是鎖。
  - 處理完（或放棄）回 Z0。這趟只到鎖，不會重新開放區域，所以第 9 節第 2 題「同一個階段不能重訪」不變，這是唯一的例外。
- **錯過就沒了的鎖**（`now:1`）：瓦斯快爆了、有人被壓在下面等人救。當下沒有道具或沒做到，就錯過了，備忘錄寫「來不及了」。

### 14.2 期限（處理階段變換）
- 每個鎖寫上撐到哪個階段：`until:4` 表示第 ④ 階段結束前都還在。例如聖瑪莉醫院在 A.C.R.U. 進城後被燒掉，醫院的鎖就寫 `until:4`。
- 期限一過，鎖消失，鎖後面的東西也沒了；備忘錄改成「來不及了」，Z0 的「回去處理」也跟著消失。
- 期限到之前，**不管換了幾次階段，都是同一個鎖**：新階段的區域路線也一定會經過這個鎖（測試檢查），周圍的卡和敵人照新階段換。所以不會有「跨階段鎖不見」或卡住的問題。
- 期限快到時，備忘錄只寫感覺（例如「聽說那一帶撐不了多久了」），不寫天數，符合小字規則。

### 14.3 鎖後面一定值得
- 只放四種：**關鍵道具**（開別的鎖、真結局需要的東西）、**真結局線索**、**捷徑**（例如醫院電梯直達四樓，下次跳過一層）、**NPC 的生死**。
- 不放普通物資（食物、水、繃帶、子彈）。測試檢查每個鎖都寫了 `prize` 而且屬於這四種。

### 14.4 多種解法（多周目）
- 每個鎖有 2～3 種解法，例如：打火機／燃燒瓶／力量硬撬（會受傷、警戒變高）。
- 硬來的解法用現有的屬性檢定，有代價；QTE 照舊只靠玩家反應，不提供擲骰替代。
- 打火機、手電筒本來就是建角可以帶的初始物品（`LOADOUT`）。玩過的人下一局可以先帶，或改走別條路。這是**玩家自己記住**，遊戲不記跨局的東西，沒有違反「不做跨局記憶」。
- 鎖可以跨區域：醫院的鎖要的保險絲在配電站，這樣城市各區連在一起。每把鎖至少要有一種解法，在期限前、同一局裡拿得到（測試檢查道具真的有出處）。

### 14.5 格式
```
PUZ = { 鎖id: {
  a:'O', at:'O7|打開機房的門',          // 哪個區域、哪張卡的哪個選項
  t:'地下機房的鐵門', why:'門被電子鎖鎖住，配電箱裡少了一根保險絲。',  // 沿用 lock 的寫法
  back:1,                               // 或 now:1
  until:4,                              // 撐到第 ④ 階段
  keys:[{req:'fuse'}, {req:'pliers',k:'INT',d:14,hurt:1}],  // 幾種解法；小字只寫需要什麼
  near:{1:'O7a',3:'O7b',4:'O7c'},        // 回頭時鎖前面那張卡，依階段
  prize:{type:'short', ...}              // key／clue／short／npc
}}
```

## 15. 飢渴、疲勞與睡覺（主人 2026-11-20 決定）
現況（v0.41.0）：
- 飢餓、口渴各 10 格。普通難度大約每 5 小時口渴 −1、每 7.5 小時飢餓 −1。
- 兩個的後果完全一樣：只有歸零時，所有屬性 −2、每 2 小時生命 −1，沒歸零前沒有影響，所以玩家能硬扛。
- 睡覺是「睡到天亮（5 點）」，只能晚上睡，會回一半生命、降恐懼。不睡沒有任何懲罰。

主人要的感覺：前期還有機會恢復，後面越來越嚴峻；缺食物能硬扛，**缺水要有嚴重後果**，逼玩家積極去找。

### 15.1 扣的速度
不變（`passTime` 的 4 小時、6 小時，乘上難度的 `food`）。嚴峻感靠 15.4 的「拿得到的東西越來越少」。

### 15.2 飢餓與口渴分開
| 狀態 | 條件 | 後果 |
|---|---|---|
| 肚子餓 | 飢餓 3 格以下 | 疲勞累積得比較快 |
| 餓壞了 | 飢餓歸零 | 力量、體質 −2；每 6 小時生命 −2 |
| 很渴 | 口渴 3 格以下 | 疲勞累積得比較快；感知、智力 −2 |
| 快脫水 | 口渴 1 格以下 | 所有檢定 −2；睡覺沒辦法完全消除疲勞 |
| 脫水 | 口渴歸零 | 每 1 小時生命 −2，大約半天內倒下；沒有隊友救就會死 |

- 減值不疊加：快脫水的「所有檢定 −2」已經包含很渴的感知、智力 −2。
- 原本歸零時「所有屬性 −2」的效果（`statMod` 的 `starved`）拆成上表，不再兩個一樣。
- 文字只寫狀態（例如「喉嚨乾得發痛」「嘴唇裂開了」），不寫數字。

### 15.3 疲勞（新系統，主人同意）
- 每個人各有一個疲勞 `p.fat`，0～8 格，醒著每 3 小時 +1（很餓或很渴時每 2 小時 +1）。
- 後果：
  - 4 格起：檢定 −1。
  - 6 格起：檢定 −2，恐懼慢慢上升。
  - 8 格（撐不住了）：在休息或安全的地方時，可能不小心睡著（自動小睡，時間照跳）。
- 減疲勞：
  - **睡覺**：固定 8 小時，疲勞清空，生命回一半（同現在）。
  - **小睡**：固定 4 小時，疲勞 −4，生命回少一點。
  - 罐裝咖啡、可樂：疲勞 −1～2，但不能代替睡覺。
- 白天、晚上都能睡（拿掉 `night:1` 的限制）。在不安全的地方睡，照現有規則可能被吵醒或被襲擊。
- 主人 2026-11-20 補充：
  - 原本的「睡到天亮／過夜」選項統一改成「睡一覺（8 小時）」，每個能睡的地方再加「小睡一下（4 小時）」。
  - 原本的睡前劇情文字保留；「天亮了」那一句只在清晨醒來時出現，其他時間換成照時間寫的句子。
  - **不睏不能睡**：全隊沒有人疲勞 4 格以上就不能睡一覺，2 格以上才能小睡（選項變灰，寫「還不睏」）。
  - 睡到一半碰到最後的轟炸警報（第 30 天清晨、換背景音樂那一刻），會被強制叫醒，只算實際睡了幾小時。
- 畫面只顯示「有點累／很累／撐不住了」，不顯示數字，位置在飢餓、口渴旁邊。
- 多人：每個人自己算，跟著 G 存檔、同步。睡覺照現在全隊投票。
- 名稱 `p.fat`、`fatStg` 已搜尋過不撞名。

### 15.4 拿得到的東西越來越少
- **① 爆發、② 封鎖，停水（第 4 天）以前**：
  - 休息點的水龍頭還有水，文字寫水壓越來越小。
  - 搜索點的食物和水跟現在一樣多。
- **停水以後**：
  - 水龍頭全乾，除非修好淨水廠（現有流程不改）。
  - 下雨的事件、暴雨可以接雨水，但要煮過或消毒，不然感染會上升（同 `tapraw` 的做法）。
- **③ 失序**：搜索點常常被搜過、只剩一點；商人的水和食物變貴。
- **④ 變異、⑤ 滅菌**：
  - 物資更少。
  - A.C.R.U. 進城後佔領淨水廠，水龍頭又停了，要再搶回來。
  - 黑市的價錢最貴。
- **能恢復的機會一直都有**：修淨水廠、傑西、黑市、雨水、救了的 NPC 送東西。
- 搜索點的「被搜過」用階段決定（`ws`），不是隨機，讓同一個地點在不同階段的感覺有差別。
