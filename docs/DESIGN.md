## 改程式的技術注意
- **`index.html` 很大，一行常常很長**，改之前先用 `grep -n` 找位置，再看那幾行。
- 大量替換用 Python 的 `assert s.count(舊)==1` 再取代，次數不對就不寫檔。這樣可以避免改到別的地方。
- **選項物件要穩定**：`usedKey` 靠 `choices().indexOf(c)` 認選項。包一層複製選項時，要像 `trustCh` 用 WeakMap 記住複製品，不然 `once` 會失效。
- `outcome()` 先套旗標再套善惡值，善惡值用 getter 時要在套旗標前先讀出來。
- **改旗標名稱或存檔結構，要在 `migrateG` 加舊存檔轉換**（例如 `c2341`→`csafe`、各樓層警戒合成 `hotel`）。
- 字型：只有遊戲文字**真的多了新字**才跑 `make_font_subset.py`，因為每跑一次檔案的位元組都會不同。跑完如果字數沒變，用 `git checkout fonts/` 還原。
- 舊測試寫的是主人**以前**的決定時：只有主人這次明確改了決定，才可以改那條測試，而且要在 PR 寫出來。`guard.test.cjs` 永遠不改。
