# QTE 重構與危險檢定 v0.65.0／Build138

依據：主人 2026-11-24 與 GPT 逐項討論後定案的 ZEROCASE_QTE_BGM_REWORK_SPEC（13 項決策）。本文件是實作紀錄與驗收清單；規則細節以規格為準。

## 1. 規則（照規格，沒有自訂數值）
- 角色規則不動：初始 8 點、單項上限 5、每級 1 點；防禦 10＋敏捷÷2、力量格擋＝力量÷3 只在近戰；逃跑、撤離照舊。
- 危險檢定沿用原本的一般檢定（d20＋能力＋原本適用的檢定加值、部位傷勢與緊繃修正），自然 1 失敗、自然 20 成功；不加命中專用的加值。檢定後還原劇情主檢定的結果（LASTJ），不影響大失敗骨折等判斷。
- 新增的 DC 普通、困難、真實一樣；原本的傷害倍率、顯示規則（真實模式不顯示難度）照舊。
- 有效防守：本回合選了對應的防守（格擋／掩蔽），而且這一招吃得到（盲目的敵人、遠近不合都不算）；給這次危險檢定 +2 一次，並照表切換能力。力量高或帶盾牌不會自動算。失敗時原本的格擋／掩蔽減傷照算；力量抵抗控制原本的格擋 +2 是另一顆骰，照舊。
- 結果：完全避開＝沒有這次的生命、感染、控制、傷勢，不擲控制抵抗、不播受傷聲；部分命中＝生命傷害、感染增量各 ×0.5 向上取整，不新增燃燒；失敗＝原本完整命中。原本已有的燃燒、流血、感染、傷勢不清除。
- 保留的 QTE 完全不動（527ms、格數、整組倒數、普通困難相同）；QTE 函式裡沒有任何骰子；沒有「改用擲骰」的選項。

- 全體／多目標：每個實際受影響的玩家各擲一次；敵人互打、NPC 不擲玩家檢定（原本的分支）。
- 可見的骰子：單一目標最多兩次（一次避傷；沒躲開時原本合併的控制／傷勢抵抗一次）；傷害骰照舊在背景擲。
- 預告文字：改成危險檢定的招式不再寫「下一回合要反應」（縱火客、噴火兵的預告同樣拿掉「到時要反應」）；飛撲、狙擊照舊。
- 舊存檔：蓄力中的招式在出手時照這張表分類（目標、冷卻、進度保留）；原本的補標記（v0.49.0）照舊。
- 偷襲開場的反應（ambushQte）不在逐招表裡，屬「毫無預警的撲擊」，保留 QTE。
