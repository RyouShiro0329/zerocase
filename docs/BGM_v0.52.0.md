## 多人與存檔

- G.fight.musicId為本場識別、musicStarted為本場是否已出手；只有本場戰鬥資料新增兩個欄位，不寫玩家永久能力或跨局記錄。
- 房主在首次攻擊前送bgm事件，隊友由原pump佇列在攻擊事件前處理；核對局別與場次，重複事件不重啟。快照、存檔與房主交接保留已出手標記。
- 本機已進battle時，同場較舊的未出手快照不使曲目倒退；新場識別清除該本機標記。
- 舊存檔缺標記時，首次恢復採遭遇曲，直到下一次實際出手。無法從舊資料確知首攻，避免憑先攻回合數推測。
