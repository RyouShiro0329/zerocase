# 鈍擊命中演出提案（只供預覽，尚未做進遊戲）

狀態：給主人選。這一支是預覽，**不改** `index.html` 的戰鬥、傷害、命中、耐久、死亡、存檔、連線封包或劇情。沒有新版本號。不要合併。

## 主人已看過預覽之後（手繪方向）

主人不要程式畫的墨環，要和現有斬擊同一套手繪刀光。長期是一種畫風，分出斬擊、鈍擊、穿刺、槍擊。鈍擊要比斬擊少紅：白光、震波、碎屑為主，只留一點紅。

目前放上卡片的是兩張 **AI 生成的單格草稿**，尚未核定，也還不是 12 格：

- `docs/blunt/drafts/ai-shockwave.png`：震波。白心、銀環。另有少紅版 `ai-shockwave-lowred.png`。
- `docs/blunt/drafts/ai-smash.png`：重砸。白光從上打下，接觸處往兩側爆開。另有少紅版 `ai-smash-lowred.png`。

原圖是近黑底 `#141412` 的 JPG。預覽把背景去掉，用和斬擊相同的位置畫在敵人卡上（卡片寬約 73%、垂直置中）。動畫是單張圖的縮放、停 70ms、再淡出，峰值放在 220ms，對齊 fist。之後若核定，要改成主人畫的 12 格，不能拿這張 JPG 當正式素材。

同一套畫風往後可以這樣分，仍然是白光為主、少紅：

- 穿刺：細的一道白光戳進去，接觸點小，沒有圓環，也沒有橫向爆開。
- 槍擊：短的白光擦過或一個小衝擊點，紅更少，不要做成刀弧，也不要做成鈍擊的圓環。
- 畫的時候把最亮的地方放在左半（立繪上）。這次試看把亮心放在圖的正中，會壓到敵人名字。

基準是 main 的 v0.37.1／Build 91。v0.37.0 寫明「玩家以斬擊命中時播放刀光；**不加入鈍擊素材**」。所以鈍擊當時刻意沒做。這次只把能做的樣子與做法攤開。

未合併的穿刺分支 `feature/pierce-vfx-v0.38.0`、`feat/pierce-vertical-vfx-0380`、`preview/pierce-hit-bar-v5` 只拿來對照接法，沒有改、也沒有併。

## 傷害類型在程式裡怎麼定

`DT.blunt` 的中文是「鈍擊」。註解寫明一把武器只有一種傷害類型。

玩家攻擊時：

1. `wdt = 技能自己的 dt，沒有就用武器的 dt`（`attack`，約第 4803 行）。目前會改寫類型的技能只有妲爾的「箱中靈・利爪」（斬擊）和「箱中靈・撕咬」（穿刺）。
2. `applyDmg` 在傳入的類型裡挑實際傷害最高的一種，寫進 `f.lastDt`（約第 4468–4479 行）。鈍擊武器只傳 `blunt`，所以命中後 `lastDt` 就是 `blunt`。
3. 近戰命中、而且 `lastDt === 'slash'`，才 `await slashAttack`。否則近戰播聲音：鈍擊播 `fist`，其他播 `knife`（約第 4856 行）。**鈍擊沒有畫面演出，扣血和 fist 同時發生。**
4. 落空、大失敗不進這段，跟斬擊一樣，沒有命中演出。
5. 抗性、弱點、硬化層、爆擊倍率都在 `applyDmg`／`attack` 裡算完。演出不能改這些數字。

敵人打玩家（槍托、槍柄、揮打、推撞，音效鍵是 `fist`）打的是玩家，不是敵人卡。斬擊演出也只畫在被玩家打中的敵人卡上。這次預覽同樣只做**玩家打在敵人卡上**的鈍擊。

## 現有斬擊怎麼接（鈍擊若要做，建議沿這條）

本機物件 `SLASH_VFX`，不寫進 `G`，不改存檔。

- 圖在敵人卡裡的 canvas（`.zc-slash-fx`），`pointer-events: none`，不擋按鈕，不把卡片撐高。
- 時點：`SLASH_TIMING` 總長 755ms，主命中 335ms。刀聲立刻排程，對齊 knife 素材峰值；生命條在主命中才 `push`／`draw`。
- 卡片微震用 CSS 變數，播完或離開戰鬥就清掉 class 和 canvas。
- `prefers-reduced-motion: reduce`：不震，停在主格淡出。
- 分頁切到背景、沒有圖、沒有 canvas、或快轉追趕（`FAST`）時，改回立刻播刀聲並更新狀態，不卡住回合。
- 連線：房主 `E('slash', {id, state})`。隊友在 `pump` 裡播 `playSlashHit`。用既有封包序號，舊序號和另一場戰鬥的快照會丟掉。房主換人時把本機序號歸零。靜音仍有動畫。
- 二連擊、橫掃是每一個真正打中的目標各播一次，中間仍是原本的擲骰。同一張圖，不按技能換形狀。

穿刺未合併分支是同一套：`lastDt === 'pierce'` 才播、事件名 `pierce`、主命中也是 335ms、畫在立繪欄，避免蓋住名字和生命。穿刺同樣是**全部穿刺共用一張圖**。

鈍擊這次的要求不一樣：不同技能要看得出差別。不能只放一張共用的撞擊圖。

## 音效實測（決定主命中放哪）

用現有檔案解碼後量的，不是手機喇叭延遲。

| 聲音 | 長度 | 取樣峰值 | 20ms 能量窗的最大處 | 現在誰在用 |
|---|---|---|---|---|
| `sfx/fist.mp3` | 784ms | **207ms** | 255ms | 所有近戰鈍擊命中（音量 0.9，最長等到 900ms，檔案本身較短，不會被截斷）。推開是 0.7 |
| `sfx/knife.mp3` | 984ms | 341ms | 356ms | 斬擊。遊戲把主格放在 335ms，和峰值對齊 |
| `sfx/smash.mp3` | 1630ms | 513ms | 648ms | 巨噬者打玩家等，**不是**玩家鈍擊 |
| `whoosh` | 合成 220ms | 一開始最大，之後衰減 | — | 彈弓。不是音檔 |

建議：近戰鈍擊的接觸瞬間放在 **220ms**（卡在 207 的峰值和 255 的能量中心之間，靠近耳朵會當成「打中」的那一下）。形狀和餘韻可以每招不同，**接觸點不要每招各錯各的**，不然 fist 對不齊。若主人聽起來偏早或偏晚，只改這個數字。

彈弓沒有檔案可對。合成 whoosh 從一開始就最大聲。彈痕放在 **20ms**，貼著起音。

不建議為了預覽改掉 fist、或讓大鎚改播 smash。那是換聲音，不是這次的畫面提案。

## 三種做法

### A. 程式繪製，不加圖（預覽就是這個）

用卡片上的 canvas 畫圓環、裂紋、灰塵、凹印，再用和斬擊同一類的 CSS 微震。沒有新的圖片檔。

- 每招可以長得不一樣，不必等圖。
- 不違反「不加入鈍擊素材」。素材指的是主人提供的圖；這條路沒有新圖。
- 檔案小，之後改時點只要改數字。
- 風險：沒有斬擊那種手繪刀光。近看是幾何墨線，不是一筆一筆的原畫。手機上立繪欄只有約 38–50px 寬，線必須夠清楚，不能做很細的裝飾。

### B. 像斬擊一樣用逐格圖

每種形狀一張主人畫的透明圖。程式只負責播、對時、清掉。

需要主人提供，**不要由這邊生成圖**。若要逐格，建議沿斬擊的 4×3、12 格，透明底，不要白底、不要字、不要血霧、不要卡通速度線。畫在立繪範圍裡，不要蓋右邊的名字和生命。顏色維持現在的暗色：骨色 `#f8dcc1`、墨棕 `#5a3632`、灰塵 `#cbb8a2`、很少的暗金 `#c8ad70`。

至少要分開的形狀：普通圓印、指虎雙印、敲頭直擊、擊倒的低塵、撬縫、橫向壓力、粉碎裂紋、橫掃的帶、敲擊的濁印、彈弓小孔。手提箱方印只有在要和拳頭分開時才需要。爆擊可以不另畫，沿用該招的圖再加震。

- 和斬擊、穿刺同一條路，原畫最穩。
- 代價：技能一多就會有很多張圖。圖沒到之前做不了。v0.37.0 已經決定當時不收鈍擊圖。

### C. 混合

主人只畫一枚共用的接觸印（或沿用以後若有的一張撞擊圖），裂紋、灰塵、震、橫帶、彈孔仍用程式按技能加。

- 圖的數量少，技能仍分得出來。
- 接觸的那一下可以有手繪的重量，其餘保持現在這種收著的墨線。
- 圖未到時，可以先用 A 上線，之後只換接觸印，不必重做每招。

### 建議

寫這份時先建議 **A**。主人看過程式墨線之後，改要和斬擊同一套手繪（B 的方向）。上面的墨線預覽留著當對照，不再當正式方向。手繪目前只有兩張 AI 單格草稿，放在卡片上試看，尚未核定，也還沒有 12 格。

正式接進遊戲時（主人點頭之後才做）：

- 新名字要用目前還沒人用的：`BLUNT_VFX`、`BLUNT_TIMING`、`playBluntHit`、`bluntAttack`、`clearBluntVfx`、`renderBluntVfx`，CSS 用 `.zc-blunt-fx`、`.zc-blunt-react`。已搜過，和 `SLASH_VFX`、未合併的 `PIERCE_VFX` 都不撞。
- 只在 `lastDt === 'blunt'` 且這一下真的打中時播。近戰把現在那聲 `fist` 挪進演出裡立刻排程，避免播兩次。彈弓不要再加一聲 fist。
- 推開沒有 `applyDmg`。若要做側移，得在推開那一行另外叫，不能靠 `lastDt`。
- 生命條比照斬擊，在 220ms 才更新。回合會多等這段演出；橫掃是每個打中的目標各等一次，和現在的斬擊橫掃一樣。
- 連線事件名用 `blunt`，帶目標與快照。序號、換房主、過期快照沿用斬擊已經修過的防法。不新增 `G` 或玩家欄位。
- 減少動態：不移動卡片，印痕淡入再淡出。
- 靜音仍有動畫。離開戰鬥、換場、分頁隱藏都要清掉位移，避免卡片停在歪掉的位置。

## 若做成正式版，會碰到的設計規則

還沒改規則。列出來給主人決定。

1. v0.37.0「不加入鈍擊素材」。A 不加圖。若選 B 或 C，就需要新圖，和當時那句有關，要主人明確說可以收。
2. 新的戰鬥演出系統。流程規定新系統先提案。這份就是提案，預覽不是上線。
3. 生命條從「結算當下」改成「音效峰值」才下降。傷害數字不變，玩家看到扣血的時間會晚約 220ms（斬擊已經是晚 335ms）。
4. 橫掃、連打、二連射會讓回合多等幾段演出。規則與骰子不變，節奏會變慢一點。
5. 釘刺球棒、釘刺木板的文字像撕裂，類型卻是鈍擊。預覽故意不畫割痕。若主人希望釘刺看起來更利，那是在鈍擊上加武器外觀，不是改成斬擊。
6. 手提箱是訪客武器。方印只表現「箱面拍上」，不加靈異。利爪和撕咬仍交給斬擊、穿刺。
7. 不改 QTE、不改骰子、不寫跨局記憶、不改敵人立繪、不加遊戲內文字（正式版若只做演出，不必重做字型）。
