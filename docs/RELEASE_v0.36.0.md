新增與調整（主人本次要求）
- 戰鬥頁面在敵人卡、行動順序條的正下方顯示所有玩家的角色卡；多人可橫向滑動查看。
- 名稱直接顯示玩家資料的名稱，不用角色職業替代。優先使用既有立繪，沒有立繪時顯示頭貼，沒有頭貼則沿用名字首字。

- 標示既有戰鬥狀態（瀕死、死亡、流血、骨折、被抓住、失衡、燃燒、腐殖、暈眩、無法行動、防守、掩護、撤離、脫隊、離線）。

- 不新增 G 或玩家資料欄位，不改存檔格式、同步協定、戰鬥規則、敵人美術或劇情；頭貼仍走原有獨立同步。
- 字型子集重新產生，兩處網址使用字型 SHA-256 前 8 碼。tests/ 與切檔工具保持原樣；tools/evacuation-browser.cjs 僅更新預期的版本文字。
