# 敵人逐招設計 v0.47.0（候選版）

基準：v0.46.1／Build 112，4513baa。新版本 v0.47.0／Build 113。主人授權先處理敵人逐招設計；燒傷、耳鳴、失溫暫緩。

## 一、判定規則

- 命中判定：普通攻擊擲命中，命中才計傷害與效果。
- 傷害型 QTE：成功完全避開；失敗承受傷害，再針對指定控制效果抵抗。
- 狙擊：保留原本掩體 QTE；失敗才進命中。QTE 時限、序列與難度差異未修改。
- 抵抗：沿用 check 與自然 1／20 規則。抓住力量12；兩種撲倒的失衡力量12；震盪重擊暈眩體質14。
- 抵抗成功只避免本次控制，不返還傷害、不清除既有傷勢；護盾阻擋狀態時不多擲一次抵抗。
- 有效格擋對力量控制抵抗 +2；體質抵抗不加值。
- 可格擋近戰 QTE：撲倒、飛撲、震盪重擊、割喉、收割。反應失敗時格擋減半，再套長柄減傷、護甲與力量格擋，計算順序與普通攻擊相同。
- 囊泡 QTE：提前掩蔽可減半失敗傷害，但污染與感染仍適用。噴吐、燃燒瓶與噴火不適用此減傷。
- 格擋、掩蔽新增說明；不恢復已刪除的獨立閃躲。

## 三、行為與相容性

- 收割者保留原本負面狀態追加行動與止血反制；割喉者新增同樣的鎖定目標止血反制，不能換打另一位流血者。目標離開或倒下也取消該次割喉。
- 預告掃射顯示實際選中的人，不再把最多三人誤寫成全體；仍使用敘述，不加目標標籤或顯示預告傷害。
- 六種近身備用招式：槍托、重槍托、槍柄、揮打、推撞為鈍擊；獵刀刺擊為穿刺。隊長指令集火為槍擊。
- 陣營互打套用逐招類型；噴吐沒有新增化學屬性，保留原本普通承傷處理。
- 掩護、集火、攻勢、射擊名額、單人受擊上限、高傷錯峰、彈匣、裝填、硬化層、回血上限、詞綴、逃跑與掉落規則保留。
- 舊存檔的已蓄力招式補上分類、控制抵抗與適用防守標記；保留目標、冷卻與戰鬥進度。
- 梟首尚未登場，本次不補造技能。ROSTER 標示「原專案」的描述是原作參考，不當作現行數值。

## 四、驗收與數值限制

- 預設抵抗難度是本輪候選值；一般角色力量0～5在DC12的基礎成功率為45%～70%，有效格擋+2後55%～80%；體質0～5在DC14為35%～60%。不含天賦、狀態等加減值。
- 專項涵蓋成功／失敗、自然1／20、先扣傷害、護盾、狙擊、止血、舊存檔與雙尺寸實際結算。
- 既有完整回歸使用無敵模式，只驗證流程與錯誤；不宣稱已完成平衡測試。手機實機待主人驗收。
