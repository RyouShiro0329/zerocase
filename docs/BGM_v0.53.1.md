# 戰鬥進場立即切曲 v0.53.1／Build120

建立時間：2026-11-23T01:52:39+08:00（Asia/Taipei）；基準main2422b43，上一版v0.53.0／Build119。

## 主人修正的正式規則
- **進入戰鬥就切曲，不等首攻。** 一般戰鬥立即播放Hitman一般段；既有警戒滿二番戰立即播放激戰段。
- 驚嚇、先攻骰、選擇行動、瞄準、防禦、裝填、蓄力與預告全部維持該段。沒有獨立遭遇曲。
- 第一次攻擊與後續攻擊都不重播。沒有人攻擊就撤離，也由已播放的戰鬥曲淡回Evil。
- 本規則明確取代v0.52.0及v0.53.0的「首次實際出手才切曲」與「無攻擊撤離不播放戰鬥曲」條件。此次只修正配樂時機，不改任何戰鬥／先攻／QTE規則。

## 程式與相容性
- syncBgmState只要G.fight存在且本人未撤離，就依本場musicIntense選battle／intense，不再以musicStarted決定是否切曲。
- startFight原有beginEncounterBgm掛點位於G.fight建立之後、第一個flush之前，因此驚嚇與先攻開始前就已播放；未改敵人生成或戰鬥步驟。
- musicStarted與既有首攻事件保留作相容標記，舊客戶端回播與本版攻擊不會重開曲；讀取尚未出手的舊戰鬥存檔也立即播放。
- 同類型的新戰鬥識別改變時從頭播放；劇情pendingBurn已開始的投瓶配樂保持銜接，不在後續建立戰鬥時重開。
- 個人成功撤離仍回Evil，留場隊友繼續戰鬥曲；戰後900ms淡回探索，音樂開關、背景暫停與OGG／MP3備援保留。
- 四個Hitman音檔、兩段切點、音量、Evil、Credits與授權完全沿v0.53.0，無素材變更；授權見docs/audio/LICENSES_AND_ORIGINS.md。
