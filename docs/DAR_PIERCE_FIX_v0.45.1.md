# 妲爾穿刺技能共用特效 v0.45.1

主人於 2026-11-21 指示：妲爾的技能也是穿刺攻擊，動畫共用即可。

## 原因與修正
v0.45.0 在近戰穿刺演出額外加入角色專武排除（`w.sig`），因此「箱中靈・撕咬」只有原穿刺音效而沒有圖集演出。本版移除該排除條件；實際造成近戰穿刺傷害時共用 `pierceAttack`，不再依專武或訪客身分排除。

## 保留的設定
- 同一套圖集、由下往上的方向、血條位置、尺寸、720ms時序、碎散收尾、原音效與音量。
- 技能原傷害、抗性計算、每場一次、耐久消耗，以及擊倒敵人後回復護盾的規則。
- 手提箱普通攻擊仍為鈍擊；利爪仍為斬擊；弓弩與槍擊不因此套用近戰穿刺動畫。
- tests/、guard、切檔工具、字型、音效與圖集檔不修改。

## 驗收
- 原專項測試中「排除專武撕咬」是前版助手自行限定的範圍；依主人本次明確指示，改驗證撕咬共用一次動畫、一次音效、使用次數與耐久不變。
- 新增撕咬擊倒敵人後仍回復護盾的檢查。
- 瀏覽器在844×390、393×690驗證妲爾的完整十二格、血條位置、原音效、原傷害與護盾、演出清除，並截圖目視。
- 完整回歸：`bash tests/run_all.sh`。手機實機待主人實機驗收。
