目前狀態：音效整理完成，**尚未修改正式遊戲或 GitHub**。

## 三個音效檔案

1. `audio/01_拉弓放箭_無命中.mp3`：**拉弓 → 放箭**（不含命中）；射偏時直接播放這一段。
2. `audio/02_血肉命中_獨立.mp3`：**獨立血肉命中**，從使用者選定的 v3 ① 版本拆出；可以自由控制延遲播放，不包含拉弓或放箭。
3. `audio/03_拉弓放箭_命中參考.mp3`：原先你選定的 **v3 ① 完整命中**（供比較用），與原版完全相同，不建議正式遊戲中固定觸發。

## 時間控制（最重要）

- `01` 的拉弓與放箭合計約 1.489 秒；放箭動作約在開始後 **0.96 秒**。
- 單獨 `02` 播放時，撞擊聲在音檔開頭約 0.03 秒後出現。
- 要重現 `03` 的時間安排：在 `01` 開始播放後約 **1.18 秒**，啟動 `02`。換算成放箭到命中，約為 **0.22～0.26 秒**。
- 若想命中快一點，就在 `01` 開始後約 **1.05 秒**啟動 `02`；要慢一些，可改成 **1.45 秒**，或由遊戲依射程控制。
- `01` 可獨立作為**射偏**，不需要另外做一段相同的音訊；避免重複資源。
- 網頁 `試聽.html` 提供可調的「放箭後幾毫秒命中」滑桿，方便手機比較。

**注意：** 此聲音是箭射入血肉的候選效果，射中金屬、牆壁或木板不應用相同血肉聲。即使有血肉聲，也不代表遊戲的流血數值必然發生變化；命中、傷害、流血仍沿用原判定。

## 技術驗證

- 3 個 MP3 音效都可由 ffmpeg 正常解碼，44100 Hz、雙聲道。
- 01／03 保留 v3 使用者選定檔案的原始位元組；分離版 02 由 v3 兩個對齊音訊差值提取，避免改變已核定的聲音。
- 差值重建的 PCM RMS 相對誤差：0.0005%（單獨 02 再次 MP3 壓縮仍可能有輕微差異）。
- SHA-256、時長、檔案大小參見 MANIFEST.json。
