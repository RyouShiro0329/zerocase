## 實作與驗證

- 自然天氣每 180 遊戲分鐘更新，使用存檔識別與時間段的穩定雜湊，不消耗原有遊戲隨機數。此版天氣影響環境聲及顯示。
- 降雨事件覆蓋保存在 weatherOverride，讀檔與多人傳輸直接延續。
- 弓箭正式使用原包 01、02 兩段；03 為參考，不再固定播放完整命中。弩仍沿用原本機械／射擊音效。
- 所有新音效逐檔比對來源清單 SHA-256；音檔未重編碼。雨聲 OGG 優先，失敗回退 MP3。
- 127 項自動測試通過，涵蓋實際戰鬥、多人排程、靜音清理、天氣變化、雨聲切換、既有地圖／任務／備忘。
