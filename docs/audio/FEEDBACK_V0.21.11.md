# v0.21.11／Build 50 玩家回饋修正

基準：正式站 v0.21.10，main ca4a4ab53a428be51c50b2383754e9251ac1b01c。

## 修正

- 恐懼每次實際增加／減少都顯示角色、差額與目前值；倍率、四捨五入、上下限不變。quiet 不再漏掉紀錄，達上限且無變化不產生假增加。安撫、鎮定劑、救醒與劇情恢復也走相同入口。讀檔遷移與角色建立不當作遊戲中變動。
- 遭遇立繪原圖都是 560 像素高，但 max-width:30vw 使寬角色縮矮。改為統一 height:min(560px,88%)、保留比例，不再用寬度限制縮小身高；人多時可橫向捲動。
- 遭遇畫面上方新增戰鬥狀態。我方偷襲顯示「我方先制」；敵方偷襲顯示「敵方突襲」並說明可透過反應解除先攻加成；一般顯示「遭遇戰」。完成擲先攻後，戰鬥列依實際排序首位顯示「我方先制／敵人先制」；第二輪起為「戰鬥中」。未修改先攻規則。
- 多人 enc 仍傳陣列，每個角色附 mode；舊版隊友可以忽略新增欄位繼續顯示立繪，新版亦可讀舊陣列。
- 狀態／隊伍每個人固定顯示自己現金，含零元，沿用 usd，不作貨幣合併。
- A2 開場撞門改為 woodimpact；成功退去後「去拍隔壁的門」改為「撞向隔壁的門」。保留人類求救拍門的敘述。
- 販賣機撬動取消 glassbreak。消防箱確實敲破玻璃仍播放破裂聲。
- 玻璃、木門、發電機素材失敗時不再用製作聲、擲骰失敗聲、怪物低吼等不相符的合成備援；素材未載入就不播該聲音。

## 需補素材

| 用途 | 本版處理 | 下一輪需求 |
|---|---|---|
| 撬動販賣機 | 不播放不相符的玻璃聲 | 金屬機殼受力、撬棒摩擦、卡榫鬆脫，依實際動作選擇 |
| 上鎖門 | 沿用自行合成卡榫聲 | D_GACHA.WAV 原始來源與可使用授權待確認，或替代素材 |

木門猛烈撞擊已有 woodimpact，這次改正使用時機，不需要再把敲門音當撞擊用。沒有為了使用素材新增劇情。

## 驗證

完整 Node VM 測試 72／72 通過，含 12,672 個既有數值對照；新增 11 項回歸覆蓋恐懼與恢復、現金、正確音效、先制文字與多人新舊資料。

只讀審查指出安撫／鎮定劑／救醒三條直接寫入恐懼仍漏記，以及新物件 enc 會讓舊隊友略過演出。已先寫失敗測試，修正後完整測試通過。立繪尺寸由 CSS 控制，沒有重製或改寫原圖。

桌面與手機的實際畫面、人耳音效及雙人連線仍以正式站實際驗收為準。VM 使用 DOM／音訊替身，不能當成手機實測。
