## 主人核准的規則變更

1. 抓住、感染者撲倒、獵食者飛撲：受傷後力量抵抗12，成功只免除本次抓握／失衡。震盪重擊：體質抵抗14，成功免除本次暈眩。沿用check自然1／20；護盾阻擋狀態時不重擲。
2. 有效格擋使力量控制抵抗+2；不加到體質。指定近戰QTE失敗可格擋減半，依既有順序套長柄減傷、護甲及力量格擋。掩蔽可減半囊泡QTE失敗傷害，感染與腐殖物保留；噴吐、火焰不適用。
3. 割喉者鎖定目標在出招前止血、倒下或離開，該次割喉落空並露出破綻，不改打別人。原收割者止血反制保留。掃射預告顯示實際目標。
4. QTE取消能力、傷勢與天賦的時間修正：固定527ms每格，等同核准預覽v2一般身手「稍快」。普通、困難3～4格，真實保留4～6格但單格同速。四格共2108ms；三格1581ms。這是整組共用時限，不是每題獨立逾時。
5. 成功輸入後才建立下一個提示；倒數持續，不重置，取消兩格一組的120ms停頓。按錯、逾時、鍵盤長按判定、前置隨機等待、位置與音效保留。手機預覽的身手／速度選單不加入正式遊戲。
6. 舊存檔已蓄力招式補上分類與抵抗標記；保留目標、傷害、冷卻及進度。既有暈眩、骨折仍保有其他效果；只取消其QTE時間影響。環境與傷勢說明同步移除QTE影響。
