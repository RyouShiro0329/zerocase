## 玩家可見的變更

- 新增初始主動技能「撤離路線」：使用者擲統帥，成功全隊撤離，也帶走瀕死隊友；每位持有者每場一次，失敗仍消耗行動與次數。
- 普通逃跑改為個人敏捷判定，不限次數，每次花一個行動；成功者先到戰鬥外的臨時安全區等待，不再被攻擊或支援戰場。
- 緊急撤退保留敏捷逃跑 +5，但只撤離本人。
- 普通逃跑留下的瀕死隊友，要等隊伍離開原區域才勉強逃出會合，歸隊生命為 1；同區域不能遠端救援、休息或轉交物品。
- 撤離路線帶走的瀕死隊友仍需救援，可立即使用原有救援道具；撤離與歸隊不清除流血、骨折、感染、恐懼、腐殖物、燃燒等負面狀態。
- 禁止逃跑地點沿用原限制；個人逃跑只受本人被抓影響，全隊撤離須先解除現場隊友抓握。
- 補齊正楷字型的「瀕」字，更新字型網址雜湊；英文字型與所有既有音效、立繪未變。

## 主人定案的規則變更（給 Claude 接手）

1. 普通逃跑由全隊一次成功，改為個人敏捷成功、個人先撤離；失敗者仍留在戰場，每人可不限次數嘗試，但每次都消耗行動。
2. 緊急撤退只撤離本人，保留敏捷 +5、每場一次。
3. 撤離路線用統帥取代敏捷，難度沿用逃跑的 12；每位持有者每場一次，不疊敏捷逃跑的腳程快／敵人跛行加值；成功帶走全隊和瀕死者。
4. 安全區是本場戰鬥外的等待狀態，不是地圖休息點，不回血、不支援、不受擊、不拿後續戰鬥經驗；戰鬥結束後會合。
5. 普通撤離後留在原區域的瀕死者無法遠端被救起或操作，隊伍離開該區域才以生命 1 歸隊；理由是撤離者引開敵人，讓瀕死者有機會逃出。負面狀態保留，需要自行修整。
6. 移除瀕死判定自動止血；保護撤離者與脫隊者的傷勢，避免開戰、結算、換區或舊出口流程順便清除。戰場抓握、掩護與護盾等關聯仍依戰場結束解除。
7. 撤離路線帶走的瀕死者可立即使用原有救援道具，不免費救起；被帶走者不套換區自動回血。真實難度也允許脫隊者以生命 1 歸隊，其他倒地規則保留。

- 狀態放在 G：本場等待 `G.fight.escaped`、脫隊原區域 `p.leftBehind`、保留傷勢 `p.evacWounds`、被帶走的瀕死者 `p.evacCarry`。沒有挪用網路斷線用的 away。
- 先攻、同時選行動、敵人預告／全體攻擊、經驗、物品轉交與救援都排除不在現場的角色。

- 如果剩下的人倒下，但已有清醒角色逃出，不判定全隊死亡；若敵人已全部倒下，仍走獲勝結算。
