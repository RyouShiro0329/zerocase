# 給接手的 AI：零號病例的工作方式

主人（了白）會輪流用 Claude（露涅希亞）和 GPT 更新這個遊戲。**以 Claude 為主**：Claude 負責整合、守設計規則、維護 Claude 專案裡的交接文件（HANDOFF.md）。這份是兩邊共用的最低規則。

## 正本
- **這個倉庫的 `index.html` 是遊戲正本**。每一版的 commit 列在 `docs/VERSIONS.md`，要找舊版就 `git checkout <commit> -- index.html`。
- Claude 那邊把 index.html 切成 15 個原始碼檔（`tools/split_index.py`），改完再用 build.sh 組回來；組回來的 index.html 會和這裡逐位元相同。**直接改 index.html 沒問題**，但不要改每個模組的第一行標題（切檔靠它）：
  `const ITEMS={`、`/* ============ 能力 ============ */`、`/* ================= 第一章：旅館 ================= */`、`/* ================= 第一章延伸：旅館加長 ================= */`、`/* ================= 第一章：更多隨機事件 ================= */`、`/* ================= 休息點、商人、人性值 ================= */`、`/* ================= 基礎 ================= */`、`/* ================= 音效 ================= */`、`/* ================= 生存值 ================= */`、`/* ================= 戰鬥 ================= */`、`/* ================= QTE：`、`/* ================= 連線 =================`、`/* ================= 遊戲畫面 ================= */`、`/* ================= 選單、建立角色、房間 ================= */`
- 所有程式在同一個 `<script>` 裡，共用同一個全域範圍：**新增函式前先搜尋名稱有沒有重複**。

## 每次發布前
1. `bash tests/run_all.sh`：Node 邏輯測試（tests/*.test.cjs）＋瀏覽器冒煙測試＋長路線測試（後兩項有 playwright 才跑，整套約 6～7 分鐘）。全部通過才發布。
   - 瀏覽器的兩項都開**測試用無敵模式**（`tests/helpers/godmode.cjs`，只在測試頁注入，遊戲本體沒有這個開關）：主人 2026-11-16 說現在不測平衡，測的是程式錯誤、去處、文字。之後做平衡測試時要另外跑、關掉無敵。
   - 長路線測試（`tests/long-route.cjs`）會從旅館一路往沒去過的地方走（避開最終結局與撤離巴士），檢查節點與選項去處都存在、紀錄裡沒有 undefined／NaN。急著看結果可以 `SKIP_LONG=1 bash tests/run_all.sh`，但回報要寫長路線「未測試」。
2. `tests/guard.test.cjs` 是主人定案的設計規則（不寫喪屍殭屍、沒有中國大陸用語、美國城市沒有台灣地名、QTE 規則、10 天、節點去處、函式不重複）。**測試失敗代表改壞了，不要改測試去配合**；規則要改，先問主人。
3. 版本號照語意化版本：修正＝patch、新內容＝minor。主選單的版本行 `const ZC_VER=` 要跟著改。
4. 寫一份發布說明（改了什麼、跑了哪些測試、結果、沒測的和原因），放 `docs/` 或 `更新說明.txt`，commit 訊息寫版本號，並在 `docs/VERSIONS.md` 表格最上面加一行（版本｜commit｜說明）。
5. 遊戲文字加了新字、guard 的「遊戲文字沒有缺字」失敗時：`pip install fonttools brotli` 後跑 `python3 tools/make_font_subset.py`，重做正楷字型子集和 `fonts/coverage.txt`。
6. 劇情節點代號（N 裡的鍵）不能重複；新地點先搜尋代號有沒有被用過。

## 主人的設計決定（摘要，完整版在 Claude 專案的 HANDOFF.md）
- 舞台是 2038 年的美國城市；遊戲文字用台灣繁體中文用語。
- 感染者是「還維持大部分人類外觀」的那一類敵人統稱；不寫喪屍、殭屍。
- A.C.R.U. 是秘密部隊，一般文字只寫「穿黑色制服的人」「沒有標示的車」。城裡沒有國民兵（只在北口檢查站、撤離巴士）。
- 不做跨局記憶、不做配方記錄（配方只列這一局做過的）。
- QTE 只能靠玩家反應，不提供擲骰替代；普通和困難的 QTE 完全一樣，只差受到的傷害。
- 數字盡量不顯示；時間只顯示天數與時段；**恐懼只顯示階段名**（v0.21.11 起紀錄有寫數字；主人 2026-11-16 說先暫時保留）。
- 敵人立繪只用主人提供的美術，不自己生成。
- 重大改動（新系統、改核心規則、刪內容、改劇情走向）先提方案給主人。
- 測試結果只寫通過／失敗／未測試；手機實機一律寫「待主人實機驗收」。

## v0.35.0 撤離規則（主人 2026-11-18 定案）
- 普通逃跑各人擲敏捷，難度沿用 12；每次用掉行動、不限嘗試次數。成功只撤離本人。
- 緊急撤退也只撤離本人，保留這次敏捷逃跑 +5、每場一次。
- 初始技能新增「撤離路線」：使用者擲統帥，難度 12；每位持有者每場一次，失敗仍消耗行動與次數，成功全隊撤離並帶走瀕死隊友。敏捷逃跑的天賦／敵人跛行加值不套到統帥檢定。
- 普通逃跑者在戰鬥外的臨時安全區等待，不是地圖休息點：不被攻擊、不支援、不取得後續戰鬥經驗；剩下的人打贏或撤離後會合，等待不回血。
- 普通逃跑不帶走瀕死隊友：最後仍能操作的人撤離後，未被帶走的人留在原區域，無法操作、使用物品、接受遠端救援或休息；隊伍真正離開原區域才歸隊。設定：剩下的人引開敵人，讓瀕死隊友勉強逃出會合。
- 脫隊者歸隊只恢復到生命 1，保留流血、骨折、感染、恐懼、腐殖物、燃燒與其他既有傷勢；包含真實難度，不套舊換區 25% 回血或出口復原。換區當下不先扣一次傷口傷害，讓玩家有機會自行處理。
- 撤離路線帶走的瀕死者仍然瀕死，可立即用原有救援道具，不免費救起；傷勢與負面狀態不會因撤離或歸隊清除。
- 禁止逃跑的外牆仍不能逃跑。個人逃跑只檢查自己有沒有被抓；全隊撤離須先解除現場隊友的抓握。
- 新增狀態：`G.fight.escaped` 是本場安全區等待名單；`p.leftBehind` 是脫隊時的原區域代號；`p.evacWounds` 防止舊開戰／結算順便清傷勢；`p.evacCarry` 防止被帶走的瀕死者自動換區回血。重新救起會清除 evacCarry。這些狀態存於 G，存檔與房主交接會一起保存；不挪用連線用的 away。
- 真正解除戰場抓握／掩護與護盾屬於結束戰場關聯，不代表治好身上的傷勢。
- 額外驗收：`node --test tools/check_evacuation.cjs`；瀏覽器：本機開 8768 後 `NODE_PATH=$(npm root -g) node tools/evacuation-browser.cjs`。不修改既有 tests/ 或切檔工具。
