# 一般武器穿刺特效 v0.45.0

主人於 2026-11-21 核准「斬擊式碎散收尾」預覽並授權實作部署。

## 核准外觀與素材
- 前六格採已認可的斬擊質感穿刺圖；後六格採最後核准的碎散修訂圖。按預覽相同裁切範圍組合為 `fx/pierce-12.webp`，無損 WebP、透明背景，1080×1560，4×3，每格 270×520。
- 來源：主人提供的原穿刺圖、倉庫既有 `fx/slash-12.webp` 作風格參考，再依主人逐次指示編修；不是敵人立繪。沒有新增音效。
- 向上推進、血條中央命中、排除立繪。圖格 7～12 逐格斷裂碎散，不是固定輪廓透明度淡出，不回抽。
- 正式版前六格與後六格皆對應核准預覽；不採用曾被主人否決的幾何硬邊暗紅版本。

## 實作與音效
- `PIERCE_TIMING`：12×60ms＝720ms；第5格240ms更新生命條。聲音沿用 `snd('piercehit',.9,1200)` 既有事件、音量、檔案，主要撞擊約200～300ms；預載圖集後才開始音畫，避免載入拖延。
- 核准預覽的 Audio 延遲40ms；正式版保留既有原音效事件即時播放，主要撞擊段仍涵蓋240ms命中格。原檔不裁切、不變速、不變調。正式聲畫需用實際攻擊另行驗收。
- 長度依斬擊尺寸參考 `min(卡寬×0.73,卡高×2.15)×282/432×2.4`，寬高比270/520；命中點為血條寬度52%處，沿卡片本身座標計算，支援直拿自動旋轉。
- 一般近戰穿刺由原 `attack` 呼叫，涵蓋原本走相同流程的反擊與武器技能。弓弩、槍擊、斬擊、鈍擊與落空不套用；專武撕咬仍保留原音效而不套用一般圖集。
- 聲音沿用舊 `s` 事件，新增 `pierce` 事件只負責畫面與狀態。遠端沿用既有狀態序號水位，避免過期事件回寫；靜音仍顯示特效，素材失敗仍完成原傷害，減少動態時固定命中圖格。
- 不改傷害、命中、抗性、耐久、存檔、劇情、字型與其他特效。
