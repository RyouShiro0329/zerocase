# 零號病例 v0.22.1・Build 53

## 修正
手機較窄的橫向畫面套用 compact-tools 時，v0.22.0 曾把整個頂端欄改成兩列：地點與時間先佔一列，八個工具按鈕再佔一列，因此天象、天數與警戒被推到右上方並增加高度。

本版恢復單列排列：左側地點、中段天象／天數／警戒、右側功能按鈕；為中段保留固定空間，工具按鈕縮減水平留白，地點副標過長時以刪節號顯示。移除窄畫面隱藏警戒值的舊規則。遊戲邏輯與既有存檔格式不變。

## 驗證
- 既有與新增 Node 測試合計 106 項，全部通過。
- tests/topbar-preview.html 使用正式樣式與正式 layout 函式，重現舊版 768 × 354 跑版，並檢查修正版 640 × 360、768 × 354、896 × 414、1024 × 480 與 432 × 936 直拿自動旋轉。
- 檢查項目：同列、頂端高度、警戒可見、中段完整、欄位不重疊、按鈕不溢出、按鈕高度及八個功能鍵。
- 瀏覽器尺寸驗證並非 Android 裝置實機驗收。

實際瀏覽器結果：舊版頂端高度 77 px，修正版五種尺寸皆為 42 px，八項幾何／可見性檢查全部通過。
