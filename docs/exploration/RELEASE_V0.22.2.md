# 零號病例 v0.22.2・Build 54

## 依使用者更正的資訊紀錄規則
- 「地圖樹」為溝通時的結構稱呼；正式按鈕與面板標題改為「地圖」。
- 備忘錄只列已發現的鎖門、受阻入口與現場可知的特殊工具需求。一般商人介紹、人物對話、案件資料、影像與世界情報不自動抄入。
- 相關電力、供水、門禁與工具線索只更新原本那筆入口紀錄；不生成探索路線或解謎步驟。
- 任務只在玩家明確承接既有 NPC 請託時登記。單純看見 NPC、交談、取得情報、停電、恢復設施與移動均不自動建立任務。
- 任務標題預設收合，點開才顯示委託人、接取地點與已揭露條件。備忘錄也採收合清單；目前狀況與先前紀錄分開，避免全文重複。

## 現有事件接入
只為原有選項「跟他們出去救人」與「幫他們把油罐車灌滿」增加接取／結束紀錄，沒有新增劇情選項或獎勵。消防隊救人戰鬥勝利後完成、逃跑後中止；油罐車協助事件結束後完成。同一結果旗標可能有多種來源，因此不從 fdopen、pprd 等旗標推定玩家接過任務。

## 舊存檔
紀錄結構由 v1 升為 v2，移除自動對話備忘與「離開旅館／恢復電力／撤離」等推定目標。保留已知入口、地圖到訪紀錄、角色、物品、遊戲時間、旗標與敘事紀錄。無法由舊資料證明曾接受的 NPC 請託不回填。

## 驗證
112 項自動測試全部通過。獨立審查未發現重要缺陷，另外實際跑過消防隊請託的勝利與逃跑結算。測試涵蓋無任務初始狀態、雜談排除、門禁更新、特殊工具、舊檔清理、NPC 明確接取、條件收合、地圖名稱與原有橫向頂端欄。
