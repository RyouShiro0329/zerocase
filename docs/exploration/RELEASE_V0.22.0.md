# 零號病例 v0.22.0

## 內容
- 選項單一用途前綴：任務／對話／事件／調查／移動／搜尋／休息。
- 頂端地圖樹／任務／備忘錄。地圖唯讀，依建築與樓層標示隊伍位置。
- 已發現鎖門與障礙雙重記錄；新線索即時更新同一筆並保留歷程。
- 查閱不消耗行動；新內容有通知及個人未讀圓點。
- 延用單檔 HTML；音效、圖片、字型、既有劇情、選項索引與戰鬥規則不變。

## 存檔
可讀既有 v9 格式存檔。首次載入由到訪旗標與已取得線索補回可確定資訊；舊檔未記錄的調查文字無法還原，需重新調查。紀錄隨單人存檔及房主快照保留；已讀狀態依局號與玩家分開。

## 驗證與限制
完整 Node 測試結果見 TEST_RESULTS.txt。包含新功能 25 項與既有測試 79 項，共 104 項。
獨立審查指出出口漏記、G4 螢幕提前記錄與其他鎖門漏記，均新增重現測試修正。
已於線上頁面驗證既有存檔載入、三個新面板、目前樓層、任務進度與未讀清除；同房間重複列出已修正。另以實際 draw/panel 程式做重繪與唯讀測試。Android 實機觸控及多人真實連線仍需驗收。

## 手機操作
解壓縮完整包後開啟 zerocase/index.html；字型、圖片及音效資料夾保持同層。線上版請重新整理，必要時關閉舊分頁再開。
地圖只能展開／收合，無法點地點旅行。移動仍使用原行動選項。

## 實作決定
眼前出口以明列路線表判定，避免用途前綴漏記。未知目的地先顯示玩家看到的出口名稱，歸在發現位置；實際抵達才顯示完整地點。備忘錄保留原劇情已揭露資訊，不生成解謎答案。
