# v0.44.1 鈍擊音效與血條位置修正

- 基準：main `2aa7cc42c9c6c9f2c2e4ac0531134782839a42a4`（v0.44.0／Build 106）。
- 版本：v0.44.1／Build 107。
- 主人要求：恢復既有鈍擊音效；12 格特效改在敵人血條區域，不在立繪。主人於本輪明確指示「恢復 然後直接部署」。

## 改動範圍

1. 使用既有 `sfx/fist.mp3`，檔案、播放上限 900ms、音量參數 0.9 與原本一致。移除 v0.44.0 加入的合成聲及其目前製作名單文字；歷史授權紀錄保留並補註已停用。
2. 使用同一張 12 格透明特效圖，總長維持 540ms。音效從演出開始播放，原檔約 200ms 的主要撞擊對齊第 6 格及血條狀態更新，不裁切音檔。
3. 鈍擊特效以目標敵人血條中心定位，裁切範圍限制在右側資訊欄；直拿轉橫向以卡片內部座標計算，排除立繪區域。短促震動改在血條，立繪不震動。
4. 不更動斬擊、穿刺、命中、傷害、抗性、弱點、耐久、劇情、存檔或模組標題。`tests/` 與 `tools/split_index.py` 未修改。
